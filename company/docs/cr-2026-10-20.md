# 公司改造 CR 修复验收

本轮复核维护脚本与 Nikou 桥接、资源传递改造，修复以下已确认问题。

| 问题 | 修复与验收 |
| --- | --- |
| 验收继承真实 Agent 配置和密钥 | 使用上游 agentenv 清单清除环境，并重定向配置根；覆盖 Codex、Claude、Qoder、OpenCode、XDG 及密钥用例 |
| 冲突期间人工锁文件被覆盖 | 未完成集成不放行脏锁；实际临时 Git 冲突恢复测试验证保留人工修改 |
| 安装期间人工切换指针被覆盖 | 激活前比较初始指针；自检期间模拟人工切换，拒绝激活并保留人工指针 |
| 未获得互斥锁仍覆盖维护状态 | 仅跳过；对正在运行的真实维护任务验证 latest.json 字节不变 |
| 搁置超过一天或上游前进导致无法恢复 | 恢复绑定已保存候选及摘要，继续原 SHA；锁、策略、公司提交、分支身份仍严格校验 |
| Nikou 独立 MCP 字段及环境引用不兼容 | 展开环境引用、缺失时报错、Codex 转换请求头字段；保留凭据禁止命令行传输规则 |
| Job 写请求失去回执被当作明确失败 | 传输失败、损坏 JSON 或无效结构返回 OPERATION_UNKNOWN，避免自动重复提交 |
| 未知回执超过一天被清理并重放 | 只有成功和明确失败可过期；running/unknown 跨重启保留 |
