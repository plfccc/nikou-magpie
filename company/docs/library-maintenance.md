# 资源库检查与维护

运行 `node company/scripts/audit-library.mjs`，检查当前用户的 Magpie 资源库与 Claude、Codex、OpenCode、DSH、Alma 的技能分发。脚本只读，输出技能数量、已分配数量、共享继承数量及问题，不输出 MCP 凭据。退出码为 0 表示检查通过；未覆盖的其他 Agent、插件内置技能及 MCP 服务连通性不在其验收范围。

共享目录中的技能可能已经被引擎读取，不应为了让专属目录有同名文件再复制一份。Magpie 会识别位于 `~/.agents/skills` 的资源库技能，并移除自己曾分发的重复入口。配置中的分配范围与引擎额外继承的可用范围应分别理解。

## 1.0.1 的 Nikou 修复

Nikou 原先使用 `Dirent.isDirectory()` 过滤技能，遗漏 Windows 目录联接及符号链接。现在跟随目录链接识别技能，忽略失效链接，并在能力快照、群关联候选与技能页中合并共享及继承目录。同名项优先使用引擎自身目录。继承技能显示“继承可用”，不能从单个引擎的页面误删共享内容。

新增隔离回归覆盖普通目录、目录链接、失效链接、共享继承、同名优先级及共享技能删除保护；旧实现会漏掉链接技能。Nikou 完整测试、构建和隐私扫描通过。运行中的 Worker 不因资源库维护自动重启。
